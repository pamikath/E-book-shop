# 🌿 LeafBook - E-Book Store Web Application

ระบบเว็บแอปพลิเคชันร้านค้า e-Book **LeafBook** ถอดแบบ UI และฟังก์ชันครบทั้ง 9 หน้าจอตามภาพตัวอย่าง 100% พัฒนาด้วย React + Vite + Tailwind CSS

---

## 📱 รายละเอียดหน้าจอทั้ง 9 หน้า (Screen Overview)

1. **หน้าร้าน (หน้าแรก)**: Header โลโก้ LeafBook, แบนเนอร์ภูเขาธรรมชาติพร้อมช่องค้นหา, รายการหนังสือแนะนำ (Atomic Habits, The Mountain Within, ดวงดาวในคืนที่มืดที่สุด) พร้อมปุ่มหยิบใส่ตะกร้า
2. **รายละเอียดสินค้า**: ปกหนังสือ, ชื่อเรื่อง, ผู้แต่ง, เรตติ้งรีวิว, ราคา, เรื่องย่อ, แท็กสเปก (ประเภท, จำนวนหน้า, รูปแบบ PDF), ตัวปรับจำนวนเล่ม, ปุ่มหยิบใส่ตะกร้า และปุ่มซื้อทันที
3. **ตะกร้าสินค้า / Checkout**: Stepper 3 ขั้นตอน (ตะกร้า -> ข้อมูลผู้ซื้อ -> ยืนยันคำสั่งซื้อ), รายการสินค้า, ปรับเพิ่ม-ลดหรือลบ, คำนวณยอดเงินรวม, ฟอร์มชื่อและอีเมลผู้ซื้อ
4. **Mock Payment (จำลองชำระเงิน)**: แถบแจ้งเตือน DEMO ONLY, สรุปเลขที่คำสั่งซื้อ (#ORD2026001), ยอดที่ต้องชำระ, ปุ่มจำลองชำระเงินสำเร็จ และปุ่มยกเลิก
5. **ยืนยันการสั่งซื้อ / อีเมล**: ไอคอนติ๊กถูกสีเขียวขนาดใหญ่, สรุปข้อมูลคำสั่งซื้อ, กล่องแจ้งเตือนการส่งอีเมลพร้อมลิงก์ดาวน์โหลด และปุ่มเปิดอ่าน e-Book ทันที
6. **ติดตามสถานะคำสั่งซื้อ**: ค้นหาด้วยเลขคำสั่งซื้อและอีเมล, แสดงแถบ Timeline สถานะ 4 ระดับ (PENDING รอชำระเงิน -> PAID ชำระเงินสำเร็จ -> จัดส่งลิงก์ดาวน์โหลด -> เสร็จสิ้น)
7. **หน้าโปรไฟล์**: เมนูข้าง (ข้อมูลส่วนตัว, ประวัติคำสั่งซื้อ, ที่อยู่จัดส่ง, เปลี่ยนรหัสผ่าน, ออกจากระบบ), การ์ดข้อมูลผู้ใช้ "สมชาย ใจดี", ฟอร์มแก้ไขข้อมูลและเปลี่ยนรูปภาพ
8. **ประวัติคำสั่งซื้อ**: แท็บตัวกรองสถานะ (ทั้งหมด, รอชำระเงิน, ชำระเงินแล้ว, ยกเลิก), Badge สถานะ (PAID / PENDING), ปุ่มเปิดอ่าน e-Book และปุ่มดูรายละเอียด
9. **หน้าจอใน Mobile App (WebView)**: รองรับ Responsive บนมือถือ 100% พร้อมโหมดจำลองกรอบสมาร์ทโฟน (Device Simulator) คู่ และแถบ Bottom Navigation ด้านล่าง

## 🚀 วิธีการรันโปรเจกต์ (Quick Start)

เปิด Terminal ในโฟลเดอร์โปรเจกต์:

```bash
# 1. ติดตั้ง Dependencies (หากยังไม่ได้ติดตั้ง)
npm install

# 2. เริ่มต้นเซิร์ฟเวอร์สำหรับทดสอบในเครื่อง
npm run dev
```

เปิดบราวเซอร์ไปที่: `http://localhost:3000`
